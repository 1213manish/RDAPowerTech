# Client Logo Assets

Place the official logo files for each client in this folder.
The component automatically displays the logo when the file exists.
If a file is missing, the card shows a clean text-badge placeholder.

## Required files

| Client               | Filename        | Format preferred          |
|----------------------|-----------------|---------------------------|
| NTPC                 | ntpc.png        | PNG/SVG with transparency |
| DB Corp Ltd          | dbcorp.png      | PNG/SVG with transparency |
| GSPCL                | gspcl.png       | PNG/SVG with transparency |
| HPCL                 | hpcl.png        | PNG/SVG with transparency |
| Jindal Steel & Power | jindal.png      | PNG/SVG with transparency |
| BHEL                 | bhel.png        | PNG/SVG with transparency |
| Indian Oil           | indianoil.png   | PNG/SVG with transparency |
| Tata                 | tata.png        | PNG/SVG with transparency |
| Adani                | adani.png       | PNG/SVG with transparency |
| Vedanta              | vedanta.png     | PNG/SVG with transparency |
| Reliance             | reliance.png    | PNG/SVG with transparency |
| Larsen & Toubro      | larsen.png      | PNG/SVG with transparency |

NOTE: SVG files also work — just rename the extension in clients array if needed.
After adding files here, the cards update automatically (no code change needed).
